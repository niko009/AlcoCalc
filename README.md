# AlcoCalc

Full-stack калькулятор приблизительного уровня алкоголя в крови (BAC), опубликованный полностью в ChatGPT Sites.

**Production:** https://alcocalc-bac.niko009.chatgpt.site

> Расчёт является ориентировочным и не заменяет алкотестер или медицинскую оценку. Результат нельзя использовать как разрешение на управление транспортом.

## Возможности

- работа без регистрации;
- локальный профиль, активная drinking session и история в `localStorage`;
- добавление, редактирование и удаление напитков;
- текущий BAC и промилле;
- ориентировочный диапазон BAC;
- график изменения BAC;
- прогноз пикового значения;
- расчёт времени до near-zero (`≤ 0.005%`);
- завершение и просмотр истории сессий;
- опциональный Sign in with ChatGPT;
- облачная синхронизация профиля, активной сессии и истории через Sites DB;
- миграция локальных данных в облако без дублирования.

## Модель расчёта

Расчёт основан на формуле Видмарка и использует:

- плотность этанола `0.789 г/мл`;
- линейное поглощение напитка в течение 45 минут;
- единую скорость элиминации `0.015 BAC %/час` для суммарного BAC;
- коэффициент Видмарка из профиля пользователя.

Модель не вычитает скорость элиминации отдельно для каждого одновременно активного напитка.

## Стек

- React 19 + TypeScript;
- Vinext/Vite;
- Tailwind CSS;
- Recharts;
- ChatGPT Sites full-stack runtime;
- Sign in with ChatGPT;
- Sites D1/Drizzle.

Проект не использует ASP.NET Core, PostgreSQL, Supabase, Vercel, Cloud Run или другой внешний хостинг.

## Локальный запуск

Требуется Node.js `>=22.13.0` и Linux-окружение с `flock`, `curl` и GNU `timeout`.

```bash
npm ci
npm run dev
```

## Проверки

```bash
npm run lint
npm test
npm run build
```

Тесты покрывают BAC-логику, поглощение, единую элиминацию, прогноз near-zero, объединение local/cloud данных и правила предложения миграции.

## Основные каталоги

- `app/` — интерфейс и API;
- `lib/` — BAC-модель, типы и local/cloud merge;
- `db/` — схема Sites DB;
- `drizzle/` — миграции;
- `worker/` — Sites Worker entry point;
- `tests/` — автоматические тесты.

## Развёртывание

Production развёртывается через ChatGPT Sites. Идентификатор Site и логические привязки хранятся в `.openai/hosting.json`; реальные облачные ресурсы управляются платформой Sites.
