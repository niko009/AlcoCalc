# Калькулятор алкоголя (BAC Calculator)

Современное веб-приложение для расчёта примерной степени алкогольного опьянения (BAC) в крови, прогнозирования времени полного вытрезвления и ведения истории напитков на основе научной формулы Видмарка.

Приложение полностью адаптировано под мобильные устройства и десктопы. Расчёты производятся исключительно локально на стороне клиента с использованием точных математических алгоритмов (без привлечения ИИ).

## Основные возможности

*   **Главная панель**:
    *   Интерактивный круговой индикатор текущего BAC (%) и промилле (‰).
    *   Автоматическое обновление показателей в реальном времени.
    *   Ориентировочное время до полного выведения алкоголя и время наступления трезвости.
    *   Красочный график прогноза уровня BAC во времени с использованием **Recharts** (динамически перестраивается при добавлении/удалении напитков).
    *   Список напитков текущей сессии с возможностью удаления.
*   **Добавление напитка**:
    *   Быстрые пресеты для популярного алкоголя (Пиво, Вино, Водка, Виски, Коктейль, Шампанское, Коньяк).
    *   Возможность тонкой ручной настройки объема (мл), крепости (%) и количества единиц.
    *   Выбор точного времени употребления напитка.
*   **История**:
    *   Хранение всех завершенных сессий в локальном хранилище (`localStorage`).
    *   Просмотр максимального уровня BAC, длительности сессии, количества чистого алкоголя и списков употребленных напитков в прошлые разы.
*   **Профиль**:
    *   Параметры пользователя: вес, рост, возраст и пол.
    *   Автоматический подбор коэффициента Видмарка (`r`): Мужчины (`0.68`), Женщины (`0.55`), Другой (`0.61`).
    *   Возможность ручной коррекции коэффициента и полный сброс данных приложения.
*   **Дисклеймер безопасности**:
    *   При первом открытии показывается обязательное предупреждение о том, что данные являются справочными и не могут использоваться для принятия решения об управлении транспортом.

## Архитектура и математический модуль (`/src/lib/bacCalculator.ts`)

Математические расчёты вынесены в чистый TypeScript-модуль, независимый от React:

1.  **Масса чистого алкоголя (г)**:
    $$\text{alcoholGrams} = \text{volumeMl} \times \left(\frac{\text{abv}}{100}\right) \times 0.789$$
2.  **BAC (Blood Alcohol Content %)** по формуле Видмарка:
    $$\text{bac} = \left(\frac{\text{totalAlcoholGrams}}{\text{weightKg} \times r \times 1000}\right) \times 100 - 0.015 \times \text{hoursSinceFirstDrink}$$
    *(Если BAC меньше нуля, возвращается 0).*
3.  **Промилле (‰)**:
    $$\text{permille} = \text{bac} \times 10$$
4.  **Время до трезвости**:
    $$\text{hoursToZero} = \frac{\text{bac}}{0.015}$$
5.  **Динамическое моделирование**:
    Для графиков строится индивидуальная кривая выведения для каждого напитка отдельно. Это решает проблему наложения («элиминации») напитков, выпитых в разное время вечера.

## Стек технологий

*   **React 19** & **TypeScript**
*   **Vite 6** (быстрая сборка, HMR настроен для AI Studio)
*   **Tailwind CSS v4** (современные утилиты и лаконичная стилизация)
*   **Zustand** (простое и быстрое управление состоянием)
*   **Recharts** (отзывчивые векторные графики)
*   **Motion (framer-motion)** (плавные анимации переходов)
*   **Lucide React** (набор современных иконок)

## Запуск проекта

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск локального сервера разработки
```bash
npm run dev
```
Сервер будет доступен по адресу: [http://localhost:3000](http://localhost:3000)

### 3. Запуск Unit-тестов расчётов
Тесты покрывают все математические методы, проверку формулы Видмарка и динамический расчёт выведения алкоголя:
```bash
npm run test
```

### 4. Проверка линтера и типов
```bash
npm run lint
```

### 5. Сборка для Production
```bash
npm run build
```
Вывод сборки будет сохранен в папку `dist/`.
