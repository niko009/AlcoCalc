# AlcoCalc

Full-stack калькулятор приблизительного уровня алкоголя в крови (BAC),
размещённый полностью в ChatGPT Sites.

**Production:** https://alcocalc-bac.niko009.chatgpt.site

> Расчёт является ориентировочным и не заменяет алкотестер или медицинскую
> оценку. Результат нельзя использовать как разрешение на управление транспортом.

## Возможности

- полностью анонимная работа без регистрации;
- локальный профиль, активная сессия, история и собственные напитки;
- добавление, редактирование, удаление и повторение любого напитка текущей сессии;
- встроенные и пользовательские пресеты напитков;
- текущий BAC, промилле и сценарный диапазон оценки;
- график, прогноз пика и времени до near-zero;
- учёт выбранного состояния питания и скорости выведения;
- завершение и просмотр истории сессий;
- аналитика за 7 и 30 дней, сравнение периодов и дни без алкоголя;
- стандартные порции по 10 г чистого алкоголя;
- поиск и фильтрация истории;
- экспорт всех данных в JSON и истории напитков в CSV;
- устанавливаемая offline PWA;
- опциональный Sign in with ChatGPT;
- облачная синхронизация через Sites DB;
- миграция локальных данных в облако без дублей.

## Модель расчёта

Модель основана на формуле Видмарка и использует:

- плотность этанола `0.789 г/мл`;
- линейное поглощение за 30, 60 или 90 минут;
- выбранную скорость элиминации `0.010`, `0.015` или `0.020 BAC %/час`;
- коэффициент Видмарка и вес пользователя;
- несколько сценариев для диапазона минимальной и максимальной оценки.

Рост и возраст сохраняются в профиле, но напрямую в формулу Видмарка не входят.
Скорость элиминации применяется один раз к суммарному BAC.

## Стек

- React 19 + TypeScript;
- Vinext/Vite;
- Tailwind CSS;
- Recharts;
- ChatGPT Sites full-stack runtime;
- Sign in with ChatGPT;
- Sites D1/Drizzle.

Проект не использует внешний backend, ASP.NET Core, PostgreSQL, Supabase,
Vercel или Cloud Run.

## Проверки

```bash
npm ci
npm run lint
npm test
```

Тесты покрывают BAC-логику, поглощение, элиминацию, диапазон оценки,
прогноз near-zero, аналитику, CSV-экспорт, валидацию, PWA и объединение
local/cloud данных.
